# План мобильной версии r00tvpn (Android и iOS)

Только план, кода пока нет. Состояние источников — на октябрь 2026, ссылки в конце.

## Что можно перенести с десктопа, а что нет

Electron на телефонах не работает, поэтому оболочку придётся написать заново. Переносится:

- **ядро Mihomo** (Go) — на мобильных собирается как библиотека (`gomobile` / `c-shared`) и
  получает от системы файловый дескриптор TUN;
- **формат профилей и подписок** — те же Clash/Mihomo YAML, заголовки `subscription-userinfo`,
  `profile-title`, HWID-заголовки панели, User-Agent `clash.meta r00tvpn/<версия>`;
- **бренд и тексты** — цвета и токены из `src/renderer/src/assets/main.css`, иконки, переводы
  `src/renderer/src/locales/*` (русский по умолчанию);
- в варианте Г (ниже) — значительная часть React-интерфейса.

VPN на телефоне делается только системным API:

|             | Android                                                     | iOS                                                                                           |
| ----------- | ----------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| API         | `VpnService` (TUN-дескриптор в приложение)                  | Network Extension, `NEPacketTunnelProvider` (отдельный процесс-расширение)                    |
| Права       | разрешение пользователя на VPN при первом включении         | entitlement Network Extension → нужен платный аккаунт разработчика                            |
| Ограничения | фоновые ограничения производителей (Xiaomi, Huawei и т. п.) | лимит памяти расширения: официально не документирован, по замерам сообщества ~50 МБ (iOS 15+) |

Почему вариант Г реалистичен: большая часть интерфейса уже общается с ядром через
REST API Mihomo (группы, прокси, соединения, логи, режимы). На мобильных этот API остаётся,
меняется только транспорт. Код main-процесса — загрузка подписок, генерация конфига
(`src/main/core/factory.ts`), профили — это TypeScript, и его можно запускать в WebView,
заменив `fs` и `axios` на плагины Capacitor (Filesystem, HTTP).

## Рекомендация

**Решение (15.10.2026): сначала Android на основе FlClash (вариант А), iOS — следом в том же проекте.**

Почему не Clash Mi (вариант В): проверка репозитория показала, что ядро в нём не собирается из
исходников. Android-сборка ждёт готовый `bind/android/core/libclash.aar`, iOS-обвязки ядра тоже
нет, а среди открытых репозиториев KaringX этих исходников не нашлось. Форк, который нельзя
собрать из исходников, не годится ни технически, ни для GPL. У FlClash ядро открыто целиком:
Go-обвязка в `core/` (в том числе `core/mobile/`), сам Mihomo — сабмодуль `core/Clash.Meta`.

1. **Android (форк FlClash), отдельный репозиторий `r00tvpn-mobile`.** Ребрендинг по образцу
   десктопа: имя, applicationId `io.github.soulless4235.r00tvpn`, схема `r00tvpn://`, тема «Графит»,
   русский язык по умолчанию, тот же User-Agent. APK собирается в GitHub Actions и публикуется
   в Releases.
2. **iOS — в том же Flutter-проекте**, когда появится аккаунт Apple Developer: таргет iOS с
   Network Extension (`NEPacketTunnelProvider` на Swift) и Mihomo, собранным под iOS. Вариант Г
   (Capacitor + React) остаётся запасным.
3. Общие для всех платформ вещи (схема `r00tvpn://install-config`, User-Agent, HWID, тексты)
   держать одинаковыми, чтобы панель подписок видела клиентов одинаково.

## Требования и ограничения

### Apple (iOS)

- **Apple Developer Program — $99/год.** Без него нельзя ни App Store, ни TestFlight, ни
  Network Extension на устройстве.
- **VPN-приложение в App Store может опубликовать только организация** (правило App Review 5.4):
  нужно юрлицо и номер D-U-N-S (бесплатный, оформление занимает время). Там же требуется
  `NEVPNManager`, экран с описанием собираемых данных до начала использования, политика
  конфиденциальности с обязательством не продавать и не передавать данные; если в стране нужна
  VPN-лицензия, её указывают в App Review Notes. Отдельный открытый вопрос — распространяется ли
  требование организации на чистые «клиенты» без своих серверов: официального ответа Apple нет.
- **Россия.**
  - Российские карты не принимаются к оплате.
  - Юрлица из санкционных юрисдикций Apple может заблокировать.
  - Обходные способы оплаты могут нарушать условия Apple, их стоит проверить с юристом.
  - Apple удаляет VPN- и прокси-клиенты из российского App Store по требованию РКН: 25+
    приложений в июле 2024; 1 213 удалений по запросам властей РФ за 2025 год; в марте 2026
    сообщалось об удалении Streisand, V2Box, v2RayTun, Happ.
  - Практически: в российском сторе приложение, скорее всего, не будет доступно, пользователям
    нужен Apple ID другой страны.
- **Обходные каналы:**
  - TestFlight: до 10 000 внешних тестеров, сборка живёт 90 дней, тоже проходит проверку;
  - ad-hoc: до 100 устройств на год;
  - альтернативные маркетплейсы — только для пользователей в ЕС.

  Enterprise-программа для публичной раздачи запрещена.

- **Технически:** packet tunnel работает в отдельном процессе с жёстким лимитом памяти. Для
  Mihomo это значит:
  - правила в формате `.mrs`, без больших `geosite.dat` / `geoip.dat` в памяти;
  - `GOMEMLIMIT`;
  - ограничение кэшей;
  - тесты на старых устройствах.

### Google (Android)

- **Google Play Console — $25 один раз.** Для `VpnService` обязательна декларация в Play
  Console. VPN должен быть основной функцией приложения, нужны заметное раскрытие и согласие
  пользователя, шифрование до точки выхода. Запрещено использовать VPN для сбора данных без
  согласия и для манипуляции чужим трафиком ради рекламы.
- **Распространение вне Play:**
  - APK в GitHub Releases (как десктоп) с собственной проверкой обновлений;
  - F-Droid — подходит под GPL, но требует сборки из исходников без проприетарных зависимостей.

  Доступность VPN-приложений в Google Play и RuStore для России нужно проверить отдельно: я
  этого не проверял.

- Подпись APK — свой ключ (хранить в секретах CI так же, как сертификаты десктопа).

### Лицензии

- Mihomo, FlClash, ClashMetaForAndroid и Clash Mi — **GPL-3.0**. Мобильное приложение на их
  основе тоже будет GPL-3.0, его исходники нужно публиковать (как сейчас десктоп).
- **GPL и App Store:** FSF считает условия App Store несовместимыми с GPL. Прецедент — VLC,
  убранный из App Store в 2011 году после жалобы одного из авторов, и вернувшийся в 2013 году
  под двойной лицензией MPL/GPL. Mihomo-клиенты и клиент sing-box (GPL-3.0) в App Store
  публикуются, но жалоба любого правообладателя Mihomo может снять приложение. Получить согласие
  всех авторов Mihomo нереально, так что это **принимаемый риск** — обсудить с юристом до
  публикации.
- Название: не использовать «Clash» и чужие марки в имени. «r00tvpn» в этом смысле безопасно.
  У некоторых проектов есть доп. условия к GPL: например, клиент sing-box запрещает использовать
  своё имя в производных работах.

## Что понадобится от вас

- Решение по варианту после разведки.
- Аккаунт Apple Developer на организацию (юрлицо, D-U-N-S, способ оплаты) — если нужна iOS.
- Аккаунт Google Play Console — если нужен Play.
- Ключ подписи Android и сертификаты Apple — в секреты GitHub.
- Иконки и графика для мобильных форматов (adaptive icon для Android, набор для iOS).
- Юридическая проверка: GPL в App Store, работа VPN-клиента для пользователей из РФ.
